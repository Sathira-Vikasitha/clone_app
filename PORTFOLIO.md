# Pixora Portfolio Guide

Pixora is a full-stack social photo marketplace prototype. It was built to demonstrate real-world app architecture, authenticated user flows, social features, marketplace workflows, admin moderation, and deployment-ready project organization.

## Short Portfolio Description

Pixora is a social photo marketplace where users can share posts, message each other, receive notifications, save content, and sell downloadable images through a store system. The app includes demo payments, manual receipt approval, seller orders, buyer purchases, download tracking, and an admin dashboard.

## Tech Stack

- Next.js, React, TypeScript, Tailwind CSS
- Express.js, TypeScript
- Prisma ORM
- Supabase PostgreSQL
- Cloudinary image uploads
- JWT authentication

## Main Features To Mention

- User authentication and protected routes
- Social feed with posts, image uploads, likes, comments, and replies
- Profile pages and profile editing
- User search by name or username
- Real-time style direct messaging
- Notification count and notification page
- Saved posts
- Store marketplace for downloadable images
- Store categories and hashtag search
- Store item detail page
- Demo card payment flow
- Manual receipt upload and seller approval flow
- Buyer purchases page
- Seller orders dashboard
- Download tracking for paid/approved items
- Admin dashboard with protected admin access
- Pixora custom Midnight Teal UI theme
